# Community

## Public shell

```text
Community identity
Event status and year
Hosts / Voices

Overview    Ballot    Results    Members
```

Settings and event management live on a separate administrative surface — not inside the public shell.

## Required states

1. Coming soon  
2. Voting open  
3. User actively completing ballot  
4. User submitted ballot  
5. Voting closed; results pending  
6. Final results published  
7. Individual voter ballot  
8. Community settings (separate from public pages)

## v1 mode

Focus on **Official Vote** (scheduled open/close, locked results). Always-live aggregate comes later.
