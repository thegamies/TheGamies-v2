# Product

The Gamies is a consumer gaming platform centered on personal Game of the Year lists and community-run awards.

The long-term differentiator: creators, podcasts, Discord communities, Twitch streamers, publications, and other groups can run their own awards. Each event can combine audience ballots with ballots from designated hosts called **Voices**.

## Principles

1. Game artwork and rankings are the primary visual material.
2. Public pages are editorial and content-led; administration is separate.
3. Rankings should be understandable at a glance but support deep exploration.
4. Community, Voice, and Combined results stay distinct concepts.
5. Public game, profile, list, community, and results pages must be crawlable and shareable.
6. Mobile is a first-class layout, not a compressed desktop page.
7. Interface stays restrained; personality comes from composition, typography, artwork, and rank treatment.

## v1 scope

**Ship**

- Auth and basic profiles
- Enough catalog to build ballots
- Personal ranked lists
- Communities hosting **Official Vote** events
- Voices, community ballots, combined results
- Public community shell: Overview / Ballot / Results / Members
- Shareable, crawlable results and list pages

**Defer**

- Library / played status
- Always-live aggregate mode (design Official Vote first)
- Native mobile
- Reviews, messaging, complex notifications
- Heavy admin inside public community pages
- Export/share chrome beyond solid OG images when needed

## Community event modes

1. **Official Vote** — scheduled ballot with open time, deadline, locked result. **v1 focus.**
2. **Always-Live Aggregate** — ongoing ranking from members' personal lists. **Later.**

## Success loop (v1)

A visitor lands on a community event → sees status/results or opens a ballot → signs up → submits a ranked GOTY ballot (and categories if enabled) → appears in community results that are worth sharing.
